# CLIME AI Growth Studio — 왕초보 사용 설명서

전문 용어·영어 메뉴 없이, **화면에 보이는 한글 그대로** 설명합니다.

---

## 한 줄로

이 프로그램은 **오늘 무엇을 홍보할지 정하고 → 글을 만들고 → 확인한 뒤 → (가능하면) 올리고 → 파일로 남겨 두는** 도구입니다.  
“모든 SNS를 무조건 자동으로”가 **아닙니다.**

---

## 실행

바탕화면 **CLIME AI Growth Studio** 더블클릭.

---

## 홈 화면에서 무엇을 누르나 (이게 전부)

### 위에 있는 메뉴

| 보이는 글자 | 누르면 |
|---|---|
| **빠른 실행** | 검색으로 기능 찾기 |
| **주간·월간 목표** | 이번 주/달/분기 큰 목표만 보기 |
| **설정** | 앱·프로젝트·내 설정 |
| **자료실** | 메모·전략 자료 모음 |
| **올린 기록** | 예전에 올리거나 보관한 기록 |
| **전체 메뉴** | 계정·글·대기줄·성과 등 더 보기 |
| **알림함** | 진행 상황·멈춤 안내 |

### 가운데 큰 버튼 (하루 루틴)

| 순서 | 버튼 | 뜻 |
|---|---|---|
| 1 | **오늘 홍보 시작** | 오늘 할 일을 **대기줄에 넣기** (여기서 시작) |
| 2 | **글 확인** | 올리기 전에 내용 보기 |
| 3 | **자동으로 올리기** | 가능하면 SNS에 올리기 |
| 4 | **파일로 보관** | 컴퓨터에 백업 저장 (**홍보 완료가 아님**) |

### 「지금 상황」 칸

| 보이는 글자 | 뜻 |
|---|---|
| **연결된 SNS 계정** | 연결됨 / 아직 없음 (플랫폼·아이디 표시) |
| **지금 올릴 수 있음 / 없음** | 지금 자동으로 올려도 되는지 |
| **올리는 방식: 공식 연결 / 브라우저 로그인** | 어떤 방식으로 올리는지 |
| **위험도: 낮음·보통·높음** | 조심해야 하는 정도 |
| **작업 진행** | 대기 중 / 진행 중 / 검사 중 / 올리기 완료 / 확인 필요·일시정지 |
| **최근 작업 번호** | 이번 작업 일련번호 |
| **문제 추적 번호** | 문제 생겼을 때 적을 번호 |

계정이 안 보이면 → **처음 연결 도우미**로 다시 연결하세요. 연결한 계정은 앱을 다시 켜도 「지금 상황」에 남습니다.

아래 **오늘 이 일을 고른 이유** = 왜 오늘 이 홍보인지 짧은 설명.

---

## 추천 하루 순서 (이것만 기억)

1. 앱 실행  
2. (처음이면) **빠른 실행** → **처음 연결 도우미**  
   - 플랫폼 고르기 → **아이디·비밀번호** 입력 → **아이디·비밀번호로 연결**  
   - 비밀번호는 앱 금고에만 저장됩니다 (메모장에 적지 마세요)  
   - 또는 **전체 메뉴** → **계정 연결**  

3. **오늘 홍보 시작** 누르기  
4. **알림함**에서 잘 돌아가는지 보기  
5. **글 확인** → **자동으로 올리기**  
6. **파일로 보관**으로 백업  

막히면 → **알림함** + **지금 상황**의 문제 추적 번호를 보세요.

## 전체 메뉴 안 (「전체 메뉴」 버튼)

| 메뉴 | 하는 일 |
|---|---|
| **내 프로젝트** | 지금 쓰는 프로젝트 |
| **계정 연결** | SNS 계정 연결·가능 여부·안전 점검 |
| **도구·브라우저** | 프로필·파일·글자 인식 도구 |
| **글·콘텐츠** | 글 만들기·검사·다채널 변환 |
| **작업 템플릿** | 자주 쓰는 작업 틀 |
| **대기줄·키워드** | 대기 중인 일·키워드 |
| **성과 보기** | 결과·추정 숫자 (참고용) |
| **파일로 보관** | 백업 화면 |

## 알림함이 중요할 때

화면에 **「확인 필요 · 일시정지」** 가 뜨면:

1. **정상**입니다 (막힌 게 버그가 아닐 수 있음)  
2. **알림함 보기**  
3. 해당 사이트에서 **본인이 직접** 확인  
4. **확인 후 다시 올리기**  

자동으로 넘어가 주는 버튼은 **없습니다.**

---

## 자주 하는 오해

| 오해 | 진실 |
|---|---|
| 파일로 보관 = 홍보 끝 | ❌ 백업일 뿐 |
| 모든 SNS 완전 자동 | ❌ 「지금 올릴 수 있음」일 때만 |
| 영어·개발 용어를 알아야 함 | ❌ 화면은 한글로 맞춰 둠 |

- 동의 없는 대량 메시지
