## 0. Locks (non-negotiable)

| Lock | Rule |
|---|---|
| Boundary | Renderer → **IPC only** → Domain API host (main/node) → engines / repos |
| IPC channel | **`domain:<namespace>.<method>` only** — no `domain.` dot-prefix, no raw engine channels in UI |
| Envelope | Every IPC request **must** carry `{ requestId, schema_version, traceId }` (+ optional `projectId`, `args`) |
| Response | Every IPC response **must** carry `{ requestId, ok, traceId }` (+ `data` \| `error`) |
| Schema | Boundary payloads validated with **Zod** + `@clime/shared` `schema_version` |
| Async work | Long AI / publish / research / simulation → **immediate `jobId`**; UI **must not** await completion on IPC |
| Progress | Job progress → **Inbox / NotificationAPI** (Domain API push); **UI bus subscribe = 0** |
| Governance | Commands call `admit()` before side effects ([`S25A`](S25A_GOVERNANCE_CONTRACT.md)); `GovernanceAPI` mutations wrapped here |
| Buses | Command / Query / Domain / System buses = **internal only** (slice 3 `event-bus` package) |
| Trace | `traceId` mandatory on IPC + Workflow/AI paths ([`12`](../architecture/12_INFRASTRUCTURE.md) §8) |
| ORM | **not Prisma** · Supabase/Postgres client count = **0** (inherited) |

**Forbidden (merge blockers):** Renderer importing engines / Drizzle / buses / vault · `ipcMain` handlers bypassing Domain API · UI `ipcRenderer.on('*')` · open Event Bus subscription in renderer · IPC without `traceId` · long work blocking IPC await · Capability mutation from UI · Queue bypass on `automation.startMission`.

## 1. Process roles (Electron)

| Process | Runs |
|---|---|
| **Main** | Domain API host, handler registry, engine wiring, vault access, workers orchestrator |
| **Preload** | Narrow `contextBridge` — **Domain API typed client only** |
| **Renderer** | Next.js UI — Mission Center, Account Manager, etc. |

```text
Renderer
  → preload DomainClient.<namespace>.<method>(args)
    → ipcRenderer.invoke("domain:<namespace>.<method>", envelope)
      → main ipc-register → handler → engine/repo

```

Preload **allowlist:** expose `DomainClient` factory only. No `require`, no Node APIs, no raw `ipcRenderer` to renderer.

## 3. Request / response envelopes

### 3.1 IPC request (frozen)

```ts
export type DomainIpcRequest<TArgs = Record<string, unknown>> = {
  requestId: string; // ulid | uuid v4 — correlate req/res; cancel/stream token
  schema_version: 1; // @clime/shared SCHEMA_VERSION
  traceId: string; // propagated end-to-end; observability primary key
  projectId?: string | null; // active project scope when applicable
  args: TArgs; // method-specific; Zod-validated per handler
};
```

Rules:

- **`requestId`:** generated by **caller** (renderer client or main self-call). Unique per in-flight IPC invocation. Used for dedup logging, cancel, and streaming backpressure.
- **`traceId`:** generated at **UI action origin** (button click / route mount) when possible; preserved across chained Domain API calls and engine hops. Main may append child spans internally but **returns the root `traceId`** in IPC response unless documented otherwise.
- **`schema_version`:** must equal `@clime/shared` `SCHEMA_VERSION` (currently `1`). Reject unknown versions at host boundary.
- **`projectId`:** required for project-scoped Commands; optional for global Settings/Governance reads.

Zod (s3-b must implement):

```ts
import { schemaVersionSchema } from "@clime/shared";

export const domainIpcRequestSchema = z.object({
  requestId: z.string().min(1),
  schema_version: schemaVersionSchema,
  traceId: z.string().min(1),
  projectId: z.string().nullable().optional(),
  args: z.record(z.string(), z.unknown()).default({}),
});
```

### 3.2 IPC response (frozen)

```ts
export type DomainIpcResponse<TData = unknown> =
  | {
      requestId: string;
      ok: true;
      traceId: string;
      data: TData; // MUST include schema_version on object payloads crossing boundaries
    }
  | {
      requestId: string;
      ok: false;
      traceId: string;
      error: DomainError;
    };
```

```ts
export type DomainErrorCode =
  | "FEATURE_DISABLED"
  | "POLICY_DENIED"
  | "CAPABILITY_DENIED"
  | "GOVERNOR_THROTTLED"
  | "KILL_SWITCH"
  | "VALIDATION_FAILED"
  | "NOT_FOUND"
  | "CONFLICT"
  | "PROVIDER_FAILED"
  | "SESSION_EXPIRED"
  | "UNKNOWN";

export type DomainError = {
  code: DomainErrorCode;
  message: string; // human-safe; no stack traces
  retryable: boolean;
  traceId: string;
  details?: {
    schema_version: 1;
    fieldErrors?: Record<string, string[]>;
    jobId?: string;
  };
};
```

Host **must** echo `requestId`. On handler throw, map to `{ ok: false, error, traceId }` — never leak raw stack to renderer.

### 3.3 Preload client shape (frozen)

```ts
export type DomainClientMethod<TArgs, TResult> = (
  args: TArgs,
  meta?: { projectId?: string | null; traceId?: string; requestId?: string },
) => Promise<TResult>;

export type DomainClient = {
  growth: { getMissionToday: DomainClientMethod<...>; /* … */ };
  automation: { startMission: DomainClientMethod<...>; /* … */ };
  // … one property per namespace
};
```

Client responsibilities:

1. Generate `requestId` + `traceId` when `meta` omitted (`traceId` may come from React context / session store).
2. Wrap `args` into §3.1 envelope.
3. `invoke(channel, envelope)` and unwrap `data` or throw typed `DomainError`.

## 4. Command vs Query vs Async

| Kind | IPC behavior | `jobId` | Examples |
|---|---|---|---|
| **Query** | Sync read; idempotent | No | `growth.getMissionToday`, `account.getMatrix` |
| **Command** | Sync mutation; completes when intent persisted | Usually no | `governance.setFeature`, `content.validate` |
| **Async Command** | Returns **`jobId` immediately**; work continues in worker | **Yes** | `automation.startMission`, `content.enqueueGenerate`, `growth.runResearchJob` |

Classification is **fixed** in §5 method map (`[Q]` / `[C]` / `[A]`). Host must not upgrade Query to blocking long work.

## 6. `jobId` rules (async commands)

### 6.1 When required

Methods marked `[A]` **must** return within IPC timeout (target **≤ 500ms** host ack) with:

```ts
export type AsyncJobAck = {
  schema_version: 1;
  jobId: string;
  traceId: string;
  /** optional stable links for UI deep-link */
  workflowRunId?: string;
  plannerQueueItemId?: string;
};
```

UI **must** treat `jobId` as opaque handle — display progress in Inbox / status board, not block on completion.

### 6.2 `jobId` format (frozen)

```text
job_<ulid>
```

- Generated by **automation/workflow host** at enqueue time.
- **Stability:** one primary `jobId` per user-visible START/generate/research action.
- **Mapping:** host maintains `{ jobId → workflowRunId?, plannerQueueItemId?, traceId }` in SQLite via Storage repos ([`S2A`](S2A_STORAGE_CONTRACT.md)) — no ad-hoc in-memory-only maps in V1.

Preferred linkage for Mission START:

```text
startMission → plannerQueueItemId (+ workflowRunId when run created) → same traceId as IPC
```

### 6.3 Progress & completion

| Stage | UI source | Bus (internal) |
|---|---|---|
| Enqueued | Inbox item `kind: job.enqueued` | Domain `PlannerItemEnqueued` |
| Running | Inbox / NotificationAPI push | Domain + System events |
| Challenge pause | Inbox `PAUSED_CHALLENGE` + Matrix honest badge | System `PublishChallengeDetected` |
| Done / Failed | Inbox terminal + optional toast | Domain/System terminal events |

**Renderer bus subscribe count = 0.** Preload may expose `notification.subscribePush(callback)` that wraps a **single** allowlisted IPC push channel — not Command/Query/Domain/System buses.

### 6.4 Cancel

| Mechanism | Use |
|---|---|
| `requestId` | Abort in-flight **streaming** / duplicate guard |
| `automation.cancelJob` | Operator cancel `{ jobId, traceId }` |
| `workflow.cancelRun` | Cancel run by `workflowRunId` |
| Kill Switch | Governance path → bulk `CANCELLED` ([`S25A`](S25A_GOVERNANCE_CONTRACT.md) §6) |

Cancel ack: `{ schema_version, jobId, terminalState: "CANCELLED", traceId }`.

### 6.5 Stub phase (슬라이스 8)

Mission Center may call `automation.startMission` with **stub host** returning real-shaped `AsyncJobAck` + Inbox synthetic progress — contract unchanged for Phase B/C engine swap.

## 8. Handler pipeline (normative)

For each `domain:<ns>.<method>` invocation:

```text
1. Parse envelope (Zod) — reject bad schema_version / missing traceId
2. Resolve handler by channel
3. If Command or Async Command → governance.admit({ featureKey, traceId, projectId, … })
4. If Async Command → enqueue + return AsyncJobAck (§6)
5. Else execute Query/Command sync handler
6. Map result → { ok: true, data with schema_version }
7. On deny → DomainError code from AdmitDecision / validation
8. observability.record({ traceId, channel, requestId, ok }) — slice 3 observability package
```

Feature keys follow `feature.<namespace>.<method>` convention (e.g. `feature.automation.startMission`) — exact seed list in Feature Management defaults.
